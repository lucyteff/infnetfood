# InfnetFood

Aplicativo mobile de delivery desenvolvido com **React Native, Expo e JavaScript**, como projeto acadêmico do Instituto Infnet.

O projeto contempla navegação entre telas, gerenciamento de estado global, interfaces de pedidos e organização modular de componentes.

## Funcionalidades

- Login e perfil do usuário
- Catálogo de produtos e restaurantes
- Carrinho de compras e checkout
- Visualização e acompanhamento de pedidos
- Visualização simulada de restaurantes: mapa ilustrativo com marcadores interativos, informações dos estabelecimentos e acesso aos cardápios.
- Configurações e personalização de temas
- Notificações

## Tecnologias

- React Native e Expo
- JavaScript
- React Context API
- React Hooks
- Testes automatizados

## Como executar

**1. Clone o repositório:**
```bash
git clone https://github.com/lucyteff/infnetfood.git
```

**2. Instale as dependências:**
```bash
cd infnetfood
npm install
```

**3. Inicie o aplicativo:**
```bash
npx expo start
```

Escaneie o QR Code com o aplicativo Expo Go.
